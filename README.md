# Expressive Launcher

Лаунчер для Android на Jetpack Compose с тремя темами:

- **Liquid Glass** — жидкое стекло в стиле iOS 26: линза с преломлением и радужной кромкой
  (библиотека [liquid](https://github.com/FletchMcKee/liquid)), блики на значках и виджетах,
  жидкое растягивание кнопок, свои обои лаунчера.
- **Material 3 Expressive** — выразительные формы, пружинные анимации, тематические значки.
- **Material You Lite** — лёгкая тема в стиле стокового Pixel.

Также: первоначальная настройка, анимация запуска приложений из значка, настройка каждого значка
(картинка, форма, размер, название), выбор поисковика для строки поиска, виджеты, папки, жесты.

## Сборка

Android Studio, JDK 17+, `minSdk 27`, `compileSdk 37`.

```
./gradlew :app:assembleRelease
```
